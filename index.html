使用说明 / 支持范围

  

    
能做什么

    
    
      
  • 写 C / C++，语法高亮、行号、自动缩进、括号自动配对
    • 
      
  • 点「▶ 运行」直接执行，输出在「程序输出」里
    • 
      
  • 要读入数据就先在「标准输入」里写好，再运行
    • 
      
  • 报错会显示行号，点一下跳过去
    • 
      
  • 代码自动保存在这台 iPad 上，断网也能用
    • 
    

    
本地引擎（离线）支持的范围

    
已支持：基本类型、数组（含二维）、指针、函数与递归、if/for/while/switch、printf/scanf、cin/cout、string.h、math.h、cstdio/cstring 的常用函数、字符串数组。

    
本地引擎会自动做两件兼容改写（只影响运行，不改你的源码）：

    
    
      
  • 结构体：把 struct Student{...} 展开成一组按字段命名的变量/数组，a[i].score 自动变成 a_score[i]。支持结构体变量、结构体数组、二维结构体数组、char 数组成员。
    • 
      
  • scanf 读数组：解释器的 scanf 不能直接写进数组元素，会被改写成安全的读入方式（格式串里带逗号等特殊写法时不做改写）。
    • 
      
  • 中文提示：字符串里的中文会先转义、运行后自动还原，printf("平均分 = %d", s) 能正常显示。注意 strlen("中文") 这类对中文串求长度的结果不准。
    • 
      
  • enum 枚举：enum Color { RED, GREEN = 5, BLUE }; 会自动展开成整数常量（RED=0, GREEN=5, BLUE=6），enum Color c; 变成 int c;。只支持整数常量初值。
    • 
    

    
仍不支持：结构体指针 ->、结构体当函数参数/返回值、结构体整体赋值、嵌套结构体、class、模板、STL（vector/string/sort）、malloc/free、多文件链接、goto、文件读写、交互式输入。

    
这些都能用「联网真实 g++」跑：菜单 →「切换引擎」。在线模式是真正的 GCC 14（和电脑上 Dev-C++ 同一编译器家族），报错也几乎一样。代价是必须联网，代码会发送到 godbolt.org。

    
碰到不支持的写法，可以点「切换引擎」用联网的真实 g++ 跑一次（需要网络，代码会发送到第三方免费服务）。

    
和 Dev-C++ 的报错差别

    
Dev-C++ 用真正的 g++：一次能把多处编译错误、链接错误都列出来。本地引擎是解释器：通常只报第一处错误，措辞也不同，但不检查 printf 格式串这类警告；好处是数组越界、除零、用未初始化变量会直接报错并给出行号。

    
注意

    
    
      
  • 代码存在浏览器里，重要作业请用「导出备份」存到「文件」App。
    • 
      
  • 死循环会在约 2 秒后被强制停止。
    • 
      
  • 本工具不是编译器，不能替代电脑上的 Dev-C++ 做大型/多文件工程。
